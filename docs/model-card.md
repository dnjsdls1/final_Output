## 학습 데이터 후보
아래 항목은 아직 확정된 학습 데이터가 아닌 **후보**이며, 실제 사용 전 출처·이용 조건·결측치·편향을 확인해야 한다.

| 데이터 후보 | 주요 항목 | 활용 목적 |
| --- | --- | --- |
| 비식별 공개 신용정보 데이터 | 소득, 대출 잔액, 대출 건수, 연체 여부·기간, 신용거래 기간, 카드 수, 상환 결과 | 재무 안정성 또는 상환 위험 분류모형 학습 |
| 가계 재무·소비 데이터 | 월 소득, 고정지출, 생활비, 보유자산, 부채, 월 상환액 | 월 여유자금과 차량 구매 가능 예산 산정 기준 검토 |
| 차량 제원·가격 데이터 | 차량 가격, 차종, 연료, 연비, 신차·중고차 여부, 승차 인원 | 예산과 차량 선호조건에 맞는 추천 후보 생성 |
| 사용자 선호·선택 이력 | 구매 목적, 주행거리, 주요 도로, 선호 차종·연료, 조회·선택 차량 | 향후 개인화 추천 및 추천 순위모형 학습 |
| 가상 사용자 시나리오 | 비식별 예시 입력값과 규칙 기반 예상 결과 | 프로토타입 흐름과 예외 상황 검증에만 사용 |

- 실제 개인정보나 식별 가능한 금융정보는 학습 데이터 후보에서 제외한다.
- 가상 사용자 시나리오는 실제 모델 성능을 증명하는 학습·평가 데이터로 사용하지 않는다.
- 차량 가격·연비·금융비용은 실제 적용 전에 공식 출처와 기준 시점을 확인한다.

## 평가 지표 후보
모델 역할에 따라 다음 지표를 후보로 사용한다. 최종 지표는 실제 예측 대상과 정답 데이터가 확정된 뒤 선택한다.

| 평가 대상 | 지표 후보 | 확인 내용 |
| --- | --- | --- |
| 재무 안정성·상환 위험 분류 | ROC-AUC, Precision, Recall, F1-score, 혼동행렬 | 위험 사용자를 구분하는 성능과 오분류 유형 |
| 확률값 신뢰도 | Brier Score, Calibration Curve | 예측 확률과 실제 발생 비율의 일치 정도 |
| 월 납입 가능액·차량 예산 예측 | MAE, RMSE | 예측 금액과 기준 금액 사이의 평균 오차 |
| 차량 추천 순위 | Precision@K, Recall@K, NDCG@K | 상위 추천 차량의 적합성과 추천 순서의 품질 |
| 추천 목록 구성 | Coverage, Diversity | 특정 차종에 치우치지 않고 다양한 후보를 제공하는지 여부 |
| 결과 설명 | 설명 일관성, 사용자 이해도 테스트 | 동일 조건에서 설명이 안정적이고 사용자가 추천 근거를 이해하는지 여부 |

- 클래스 비율이 불균형할 수 있으므로 Accuracy만으로 성능을 판단하지 않는다.
- 추천 적합도는 검증된 확률이 아니면 `%` 대신 `추천 점수`로 표시하는 방안을 검토한다.
- 금융 판단에 활용하기 전 연령대나 특정 사용자 집단별 성능 차이와 편향 여부를 별도로 점검한다.

## 미결정 사항
- 재무 안정성 또는 상환 위험을 판단할 정답값(y)과 등급 구간
- 월 납입 가능액과 차량 구매 예산을 규칙으로 계산할지 회귀모형으로 예측할지 여부
- 차량 추천 방식을 규칙 기반, 콘텐츠 기반 또는 추천 순위모형 중 어떤 방식으로 구현할지 여부
- 재무 상태, 차량 선호조건, 가격과 유지비에 적용할 추천 가중치
- 사용할 공개 신용·가계 재무 데이터의 정확한 출처, 이용 조건과 전처리 방법
- 차량 가격·연비·제원 데이터의 공식 출처와 정보 갱신 기준일
- 학습·검증·테스트 데이터 분리 방법과 모델별 최종 평가 지표·통과 기준
- 연령대 등 사용자 집단별 성능 차이와 편향을 확인할 기준
- 추천 적합도를 `%`로 표시할지 `추천 점수`로 표시할지 여부
- 분석 결과를 확인한 사용자가 차량 비교, 조건 수정 또는 구매 계획 중 어떤 행동으로 이어질지 결정
